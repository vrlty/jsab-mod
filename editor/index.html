Getting started
1. Click Open levels folder and pick Documents\JSAB Levels
(the mod creates it the first time the game runs; the location can be changed in its config).
2. Choose a level from the list. Vanilla levels are dumped by the mod when you play a song, or all at once (with their music) by tools\extract_levels.py.
3. Edit, then Save: it's written to custom\, and the game plays it in place of that song.
In game, press F5 during the song to reload your file.

    JSAB Level Editor

    Timeline

    Click a marker to select · Shift/Ctrl+click to add to the selection · drag on empty space to box-select
    Drag markers to move them in time (snaps to the beat grid; hold Alt for free movement)
    Click the ruler to move the playhead · double-click a lane to add that hazard there · click a lane name to select all of that type
    Wheel scrolls time · Shift+wheel scrolls lanes · Ctrl+wheel zooms

    Stage

    With one hazard selected, click or drag on the stage to set its position (walls only move along their edge). Hold Alt to place off the 10-unit grid.
    A hazard with a random position is striped everywhere it can land. Tick Roll random to draw it at one concrete position instead, worked out the way the game does it: every random choice in a run follows from one room seed (new each run and restart), the hazard's order in the level and its randomOffset, so hazards that share a randomOffset roll together. With a recording open, the editor finds that run's seed from where the recording saw things land and shows the recorded run exactly (labelled "as recorded"); ↻ shows another run. Random margins span x to x + margin. Round spikes follow the game exactly; for random choices of other types the editor doesn't know yet (a wall's side, the spot of a hazard with no position), it uses the recording where it can, else a stand-in roll.
    Untick Editor to hide the editor's own drawing (outlines, stripes, arrows, labels) and see only Motion and Art; a selected hazard stays visible so you can still edit it.
    Simulate draws the common hazards straight from the level, with the game's art, wherever nothing is recorded: round spikes, walls, beams, black holes, square appear effects and DNA lines (measured against recordings). It follows your edits at once; other hazard types still need a recording.

    Keys

    Space play/pause · Home back to start · Del delete selection
    Ctrl+Z undo · Ctrl+Y redo · Ctrl+C/V copy, paste at playhead · Ctrl+D duplicate one beat later
    ←/→ nudge the selection by one snap step (or move the playhead) · +/− zoom · Ctrl+S save

    Previewing in the game

    Start the song in the game (practice mode), then press P or Preview in game: the editor saves, the game reloads your file, jumps to the playhead (minus the lead-in) and waits there. Switch to the game and press Space to play. Follow game makes the playhead track the game while it plays the same level. The pill in the toolbar shows whether the game is connected.

    Motion

    While you play a level, the mod records every hazard's real hitbox. The editor replays it on the stage (solid pink) in sync with the timeline; the strip under the ruler shows which parts are recorded. After you edit, the old motion is shown grey and dashed until you preview the level again, which records the new version.
    Recorded motion is drawn with the game's own art, exactly as the game showed it: run tools\extract_art.py once to export the art into art\ in the levels folder (no game needed), and browse it with Art library. Untick Art to see the plain hitboxes.

    Rules the game enforces

    A hazard whose warning would start before 0:00 is skipped (shown orange).
    Wall sides name the direction they travel: down starts at the top edge, up at the bottom, left at the right edge, right at the left. An unused position means the game picks a random one.
    Coordinates: x 0–1280 left to right, y 0–720 top to bottom. The stage preview is schematic, not the game's real art.

    Press Esc or click outside to close.
